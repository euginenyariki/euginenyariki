## About me

I work where technology meets business. Give me a messy problem — a network that keeps dropping, a business with no web presence, a system nobody trusts — and I turn it into something that just works.

Over the past three years I've done the full spread: Tier 1–3 IT support, network and firewall setup, cybersecurity audits, full-stack web builds, CCTV and security installations, and the sales conversations that come with all of it. I studied Business Information Technology at Zetech University because I wanted to understand the *business reason* behind the technical decision, not just the decision itself.

A few things I've actually delivered:

- Designed and deployed a property listing website for a real estate company — 60% lift in online visibility and 3× growth in digital client acquisition in six months.
- Cut IT downtime by 40% at a property firm through proactive monitoring and preventive maintenance.
- Implemented a digital inventory system in retail that reduced stock discrepancies by 25%.
- Built an automation that posts daily Kenyan market intelligence to X, still running on schedule today.

**What I'm looking for:** an IT support, systems administration, network engineering or junior full-stack role where I can own real systems and keep learning. Nairobi-based or remote.

## How I build

- Ship something that works end-to-end, then harden it.
- Keep secrets out of source code and Git history — keys are entered at runtime and held only for the browser session.
- Separate tenant data properly; an isolated workspace per customer is not optional.
- Write the README and deployment docs so the next person can actually run it.
